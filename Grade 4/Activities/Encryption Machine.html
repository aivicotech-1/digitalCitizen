Type a message, choose a key, then press Lock it slowly.

The alphabet strip (blue = your letter, yellow = steps, green = code letter)

After Z we go back to A, like a circle.

What is encryption?
  • Encryption turns a message into a secret code.
  • The key tells us how to change each letter. Here, the key is how many steps each letter moves forward.
  • Without the key, the code looks like nonsense.
  • Keep the key secret, like a password.
Where is encryption used?
  • Many chat apps, so only the people in the chat can read messages.
  • Websites with a padlock next to the web address.
  • Online banking and shopping.
  • Saved passwords on devices.
Real encryption uses very long keys and maths, not a simple step count. The idea is the same.

Use made-up words only. Never type a real password. Nothing is saved.
